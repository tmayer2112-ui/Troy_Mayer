## Qualifications (the excerpts cut off here; these come from Apptronik's sister intern postings)
- Strong C++ (and/or Python) in a Linux development environment.
- Experience developing and debugging real-time, multithreaded software.
- Experience with model-based feedback control of articulated robots and with troubleshooting hardware.
- Strong theoretical grounding in some of: dynamics, controls, estimation, data science, linear algebra.
- Tools: ROS / ROS 2, MoveIt, MuJoCo.
- Enrolled in a BS/MS/PhD program. Several Apptronik intern postings set a 3.0 GPA minimum.
